# Flappy Raven of the Celestials

Статическая игра для GitHub Pages. В ней есть ввод ника, синий ворон, четыре типа труб с гербами животных, собираемые небесные знамёна и сохранение **только лучшего результата** каждого игрока в Supabase.

## Подключение Supabase

1. Откройте проект Supabase → **SQL Editor**.
2. Вставьте и выполните весь текст из `supabase-setup.sql`.
3. Обновите страницу игры. Список «Все полёты» станет доступен.

Публичный ключ уже указан в `index.html`: он предназначен для работы в браузере. Доступ к данным ограничен политиками RLS: любой посетитель может только добавлять и читать результаты, не может их изменять или удалять.

## Публикация в GitHub Pages

1. Создайте новый репозиторий на GitHub, например `flappy-raven`.
2. Загрузите **содержимое** этой папки в корень репозитория: `index.html`, `supabase-setup.sql`, папку `assets` и этот README.
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните.
5. GitHub через несколько минут покажет ссылку вида `https://ВАШ-ЛОГИН.github.io/flappy-raven/`.

Не перемещайте `index.html` отдельно от папки `assets`, иначе изображения не будут загружаться.
